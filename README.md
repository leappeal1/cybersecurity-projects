# Two cybersecurity portfolio projects

Two independent, runnable Python projects. Both use only the standard library and include synthetic demonstrations, automated tests, and project-specific documentation.

| Project | Focus | What it demonstrates |
|---|---|---|
| [Login Sentinel](login-sentinel/README.md) | SOC / detection engineering | Log validation, sliding-window correlation, explainable alerts |
| [Integrity Watch](integrity-watch/README.md) | Host security / integrity monitoring | SHA-256 hashing, baseline comparisons, filesystem handling |

## Getting started

Install Python 3.10 or later (Python 3.12+ recommended on Windows). Open each project folder and follow its README. No package installation, credentials, accounts, network access, or deployment is needed.

## Presenting your work

Read and run each project, explain its design, and customize it before adding it to your portfolio. Each README includes a demonstration sequence, limitations, and a suggested portfolio description. Publish the two folders as separate repositories if desired. Do not publish real authentication logs, personal information, or sensitive configuration files. Sample reports are generated from synthetic data.
